## Projeto de Detecção de Ataques e Anomalias

Este projeto tem como objetivo simular diferentes tipos de ataques cibernéticos (como força bruta, DDoS e Slowloris), analisar padrões de comportamento e identificar anomalias utilizando aprendizado de máquina e visualizações de dados.

Funcionalidades
- **Simulação de Ataques**: Geração de dados simulados representando ataques cibernéticos em diferentes cenários.
- **Análise Temporal**: Agrupamento de tentativas de acesso por IP ao longo do tempo, facilitando a identificação de padrões.
- **Detecção de Anomalias**: Utilização do modelo `Isolation Forest` para identificar acessos suspeitos.
- **Visualização de Dados**: Gráficos que ajudam a monitorar e compreender as tentativas de acesso por IP.

## Ferramentas e Tecnologias
- **Python**: Linguagem principal do projeto.
- **Bibliotecas**: `pandas`, `sklearn`, `matplotlib`.
- **Google Colab**: Usado para edição, testes e execução do código de forma simples e prática.

## Como Executar
1. Clone este repositório para o seu ambiente local.
2. Instale as dependências necessárias com:
   ```bash
   pip install pandas scikit-learn matplotlib
   ```
3. Execute o código em um ambiente como o Google Colab ou localmente.
